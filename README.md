# Cafe-kiosk-Assignment



# ☕ 클래스와 객체 기반 카페 키오스크 주문 시스템

클래스와 객체를 활용해 손님이 음료와 디저트를 선택해 장바구니에 담고, 최종 결제 금액과 영수증을 출력하는 키오스크 프로그램입니다.

## 실행 방법

```bash
python cafe_kiosk.py
```

- Python 3.x 환경에서 실행할 수 있으며, 별도의 라이브러리 설치는 필요 없습니다.

## 클래스 구조

### MenuItem (메뉴)

| 구분 | 이름 | 설명 |
|------|------|------|
| 속성 | `name` | 메뉴명 |
| 속성 | `price` | 가격 |
| 속성 | `is_ice` | 온도 옵션 (ICE: `True`, HOT: `False`, 디저트: `None`) |
| 메서드 | `get_info()` | 메뉴 정보를 문자열로 반환 (예: `아메리카노 (ICE)`) |

### Order (장바구니)

| 구분 | 이름 | 설명 |
|------|------|------|
| 속성 | `items` | `MenuItem` 객체들을 저장하는 리스트 |
| 메서드 | `add_item()` | 장바구니에 메뉴 객체 추가 후 담긴 메뉴 전체 출력 |
| 메서드 | `get_total_price()` | 담긴 모든 메뉴 객체의 가격 합산 |
| 메서드 | `print_receipt()` | 주문 내역 및 총액 출력 |

### Kiosk (추가 클래스)

- 음료/디저트 메뉴판을 보여주고, 번호 입력으로 선택한 메뉴를 `Order`에 담습니다.
- 음료는 HOT/ICE 옵션을 선택할 수 있습니다.
- 잘못된 입력(숫자가 아니거나 없는 메뉴 번호)은 다시 입력하도록 처리합니다.

## 메뉴

| 구분 | 메뉴 | 가격 |
|------|------|------|
| 음료 | 아메리카노 | 3,000원 |
| 음료 | 카페라떼 | 3,800원 |
| 음료 | 바닐라라떼 | 4,300원 |
| 음료 | 녹차라떼 | 4,500원 |
| 디저트 | 치즈케이크 | 5,500원 |
| 디저트 | 초코 쿠키 | 2,500원 |
| 디저트 | 크로플 | 4,800원 |

## 사용 방법

1. 메뉴판에서 원하는 메뉴 번호를 입력합니다.
2. 음료를 선택한 경우 HOT(`h`) / ICE(`i`)를 선택합니다.
3. 메뉴를 담을 때마다 현재 장바구니 목록이 출력됩니다.
4. `0`을 입력하면 주문을 완료하고 영수증이 출력됩니다.

## 실행 예시

```
[장바구니]
 1. 아메리카노 (ICE)
 2. 카페라떼 (HOT)
 3. 치즈케이크

==================================
          영  수  증
==================================
1. 아메리카노 (ICE)           3,000원
2. 카페라떼 (HOT)            3,800원
3. 치즈케이크                 5,500원
----------------------------------
총 결제 금액              12,300원
==================================
이용해 주셔서 감사합니다!
```
